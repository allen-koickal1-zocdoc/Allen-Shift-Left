# Test Mappings

Shift-Left test mappings generated by the `test-mapping` skill. Each mapping is a flat, per-file table of every test in a scoped set, with SHA-pinned links back to the source so rows never drift.

Scope is **by owning team**. Team ownership is resolved from `plinth.yaml` (`team:` / `owner-email:`) for service repos, from `CODEOWNERS` for paths inside the `zocdoc_web` monolith, and from `OWNERSHIP.md` under `playwright/BU/` for `Zocdoc/sandbox` E2E specs.
