## Observations

- **Signature reads are unauthenticated.** Rows 11, 12, and 20 assert that `GET .../user-agreement/signature` returns 200 with no JWT, with a CSR JWT, and with a provider JWT from an unrelated practice. Whether that is intended is a product question; the tests pin it as current behavior.
- **Write paths are consistently gated three ways** — 401 (no JWT), 403 (authenticated but no role/permission), 200 (practice admin, FGA sign-UA permission, or the legal-agreement write role). Sign, copy, backfill, and audit each carry the full trio.
- **Four scaffold `ExampleTests`** inflate the raw test count by ~8%; real coverage is 48 methods.
- **`LegalAgreement.Web.IntegrationTests` contains only the scaffold test** — no product coverage in that project.
